# Configuration Templates

Use these templates based on your starting point:

- `config_importer.json`: starter template with minimum required settings.
- `config_importer_typical.json`: recommended template for most teams.
- `config_importer_full.json`: advanced reference with all available options and in-file documentation.

Excel equivalents:

- `ImportTemplate.xlsx`: starter dataset + config sheet baseline.
- `ImportTemplate_typical.xlsx`: typical dataset + config sheet baseline for common setups.
