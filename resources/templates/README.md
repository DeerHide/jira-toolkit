# Configuration Templates

Use these templates based on your starting point:

- `config_importer.json`: starter template with minimum required settings.
- `config_importer_typical.json`: recommended template for most teams.
- `config_importer_full.json`: advanced reference with all available options and in-file documentation.

Excel workbooks in this folder:

- `ImportTemplate.xlsx`: starter dataset layout (also referenced from the main README).
- `ImportTemplate_legacy.xlsx`: legacy dataset layout for older workflows.

Release-only (not always in git):

- `ImportTemplate_with_config.xlsx`: sample `Config` sheet and tables — see [GitHub Releases](https://github.com/DeerHide/jira-toolkit/releases) when published.
